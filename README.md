# LipatoS - Item Piles: D&D 5e

Системный адаптер **D&D 5e** для **LipatoS - Item Piles** в Foundry Virtual Tabletop 14.

## Версия

**1.1.0**

## Совместимость

- Foundry VTT: **14**
- D&D 5e: **5.0.0+**, проверено с **6.0.5**
- LipatoS - Item Piles: требуется установленный модуль `item-piles`

## Что делает модуль

Адаптер сообщает Item Piles, как работать с данными системы D&D5e: валютой персонажей, ценой предметов, количеством, контейнерами, редкостью, фильтрацией типов предметов и преобразованием предметов при передаче.

Без этого адаптера Item Piles не получает полноценную системную конфигурацию D&D5e.

## Зависимость

Модуль **требует LipatoS - Item Piles** и Foundry автоматически сможет предложить установить его по манифесту LipatoS.

В обратную сторону **LipatoS - Item Piles рекомендует этот адаптер**, поэтому при установке основной сборки Foundry сможет предложить установить поддержку D&D5e. Это сделано через `recommends`, а не через взаимный `requires`, чтобы не создавать циклическую зависимость.

## Установка

В Foundry VTT откройте **Add-on Modules → Install Module** и вставьте:

`https://raw.githubusercontent.com/Lipatosha/LipatoS-item-piles-dnd5e/main/module.json`

## Внутренний ID

ID намеренно сохранён **`itempilesdnd5e`**, как у оригинального адаптера, для совместимости. Оригинальный адаптер и эту сборку одновременно устанавливать не нужно.
